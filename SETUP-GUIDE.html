Vibe Sheet setup

Why remember formulas when you can talk to your cells? · Version 1.1

How your key stays safe

Excel add-in→🔒 Your Cloudflare Worker (holds the key)→Anthropic AI
  • The key lives only in Cloudflare as a secret. It is never in GitHub, never in the add-in, never sent to users.
  • The Worker only runs the Vibe Sheet prompt, so the key can't be used as a general chatbot.
  • Each person gets a daily limit (default 30 prompts), each network 300, and only your add-in's site is accepted.
  • Final safety net: a monthly spending limit in Anthropic (step 1).
Part A · One-time server setup (about 15 minutes)
1

Anthropic: key and spending limit

  1. At console.anthropic.com → API Keys → Create Key. Name it vibesheet-server and copy it.
  2. Go to Settings → Limits and set a monthly spend limit you're comfortable with (e.g. US$20).
If you pasted a key into the old add-in Settings, delete that key in the console and use this new one only in Cloudflare.
2

Cloudflare: create the storage (KV)

  1. Sign up free at dash.cloudflare.com.
  2. Left menu: Storage & Databases → Workers KV → Create (or Create instance).
  3. Name it vibesheet → Create.
3

Cloudflare: create the Worker

  1. Left menu: Compute → Workers & Pages → Create → Start with Hello World.
  2. Name it vibesheet-api → Deploy.
  3. Click Edit code. Select all the code and delete it.
  4. Open server/worker.js from the zip in Notepad, copy everything, paste it in → Deploy.
4

Cloudflare: add the secrets and storage

In your Worker: Settings → Variables and Secrets → Add

TypeNameValue
SecretANTHROPIC_API_KEYthe key from step 1
SecretADMIN_TOKENa long password you make up (for reading feedback)
Text (optional)DAILY_LIMITprompts per person per day, e.g. 30

Then Settings → Bindings → Add → KV namespace: variable name VS_KV, namespace vibesheet → Deploy.

Copy your Worker address from the top of the page, like https://vibesheet-api.yourname.workers.dev.

Test: open https://vibesheet-api.yourname.workers.dev/v1/status in your browser. Seeing "This service only works inside the Vibe Sheet add-in." means it's live and protected.
Part B · Connect the add-in
5

Put the Worker address in config.js

  1. Open config.js in Notepad.
  2. Replace https://vibesheet-api.YOUR-SUBDOMAIN.workers.dev with your Worker address (keep the quotes) → Save.
6

Upload to GitHub

  1. Your repo → Add file → Upload files.
  2. Drag in everything from the vibesheet folder except the server folder (it isn't needed on GitHub) → Commit changes.
  3. Wait 2 minutes. In Excel, close Vibe Sheet, press Ctrl + Shift + R, reopen it.
⚙ Settings should say "Using Vibe Sheet's free AI" and the bottom should say v1.1.0. No key needed for anyone.
7

Share it

Give people the manifest.xml file and these steps:

  • Excel on the web: Home → Add-ins → More Add-ins → My Add-ins → Upload My Add-in → manifest.xml
  • Excel on Windows: the shared-folder steps (File → Options → Trust Center → Trusted Add-in Catalogs).

Later, listing on Microsoft AppSource lets anyone install it with one click.

Part C · Read feedback
8

Your admin page

Open quickshortscompany-hub.github.io/vibesheet/admin.html, enter your Worker address and ADMIN_TOKEN, press Load.

You'll see today's users and prompts, and every suggestion, bug report and question (with the error that caused it). Export to CSV any time.
